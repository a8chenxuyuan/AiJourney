# agent1旅行 — 后端实现说明

## 1. 技术栈总览

后端采用 **FastAPI** 作为 Web 框架，**Pydantic v2** 做数据校验，**SQLAlchemy + Alembic** 做 ORM 和数据库迁移，**PostgreSQL/SQLite** 做关系型数据存储，**JWT** 做用户认证，**LangChain** 封装 LLM 调用，**LangGraph** 编排 Agent 工作流，**MCP** 接入高德地图等外部工具，**Qdrant** 做向量库存储，**SentenceTransformers** 生成文本向量，**Loguru** 做日志，**python-dotenv** 管理环境变量。

| 技术 | 作用 |
|------|------|
| FastAPI | Web 框架，提供 REST API 和自动文档 |
| Uvicorn | ASGI 服务器，运行 FastAPI 应用 |
| Pydantic v2 | 请求/响应模型定义与校验 |
| pydantic-settings | 从 `.env` 读取配置 |
| SQLAlchemy | ORM，操作 User、TripPlan、Order 等数据库表 |
| Alembic | 数据库迁移管理 |
| PostgreSQL / SQLite | 关系型数据库 |
| passlib + bcrypt | 用户密码加密 |
| python-jose | JWT Token 生成与校验 |
| LangChain | LLM 调用抽象、工具封装、RAG Chain |
| LangGraph | Agent 工作流编排、状态管理、人机协同 |
| MCP | 标准协议接入高德地图 MCP Server |
| Qdrant | 向量数据库，存储 Embedding |
| SentenceTransformers | 生成文本 Embedding |
| Redis / SQLite | 缓存、会话、记忆（可选） |
| APScheduler / Celery | 定时爬虫任务 |
| Loguru | 结构化日志 |
| python-dotenv | 环境变量加载 |

## 4. 整体流程实现

### 4.1 用户注册与登录流程

```
POST /api/auth/register
  → auth.py 接收 UserCreate
  → auth_service.py 校验用户名/邮箱是否已存在
  → security.py 用 bcrypt 加密密码
  → db_models.py 的 User 表写入新用户
  → 返回注册成功

POST /api/auth/login
  → auth.py 接收用户名和密码
  → auth_service.py 查询 User 表
  → security.py 校验密码哈希
  → security.py 生成 JWT
  → 返回 access_token
```

### 4.2 旅行规划主流程

```
POST /api/trip/plan
  → trip.py 接收 TripRequest，校验当前用户
  → 生成 plan_id（UUID）
  → 创建 TripPlanDB 记录，status = "pending"
  → 调用 planning/graph.py 的图执行入口
  → graph.py 初始化 TravelPlanningState
  → 按 LangGraph 工作流执行：
      IntentAgent → 并行信息收集（Attraction / Weather / Hotel / RAG）
                  → RouteAgent → PlannerAgent → BudgetAgent
                  → 条件判断 → HumanInLoopNode 或 Finalize
  → 每个节点状态通过 Checkpointer 持久化
  → 最终结果写回 TripPlanDB，status = "completed"
  → 返回 plan_id

同时前端建立 SSE 连接：
GET /api/trip/{plan_id}/stream
  → agent.py 加载 State
  → 使用 graph.astream_events 流式输出事件
  → 每执行一个节点，通过 SSE 推送给前端
```

### 4.3 人机协同流程

```
LangGraph 执行到 HumanInLoopNode
  → 调用 graph.interrupt() 暂停
  → SSE 推送 human_interrupt 事件给前端
  → 前端展示 HumanConfirmModal
  → 用户提交决策
  → POST /api/trip/{plan_id}/human_decision
  → agent.py 调用 graph.invoke(None, resume=True) 恢复执行
  → 继续推送后续事件
```

### 4.4 RAG 检索流程

```
用户填写表单或 RAGAgent 触发检索
  → rag.py 或 RAGAgent 构造查询文本
  → rag_service.py 用 SentenceTransformer 生成 embedding
  → 查询 Qdrant，返回 Top-K 文档片段
  → 重排序、去重、拼接成 rag_context
  → 注入 PlannerAgent 的提示词
```

### 4.5 爬虫更新知识库流程

```
APScheduler 定时触发 / 管理员手动触发 POST /api/crawler/trigger
  → crawler_service.py 调度爬虫任务
  → spiders 抓取目标页面
  → pipeline.py 清洗提取正文
  → 存入 CrawledDocument 表
  → 文本切分后生成 Embedding
  → 写入 Qdrant
  → 更新任务状态
```

### 4.6 支付沙箱流程

```
POST /api/payment/create
  → payment.py 接收 plan_id 和金额
  → payment_service.py 创建 Order 记录（status=pending）
  → 调用支付宝/微信沙箱 SDK 创建预支付订单
  → 返回订单号、支付参数、沙箱支付链接

用户完成沙箱支付
  → 支付宝/微信沙箱回调 POST /api/payment/notify
  → payment.py 校验签名
  → 更新 Order 状态为 paid
  → 返回成功响应
```

## 5. 关键技术点说明

### 5.1 认证与鉴权
- 使用 HTTP Bearer Token；
- Token 通过 `python-jose` 生成，过期时间可配置；
- 受保护接口通过 `deps.py` 中的 `get_current_user` 依赖注入当前用户；
- 密码使用 `passlib[bcrypt]` 哈希，不存明文。

### 5.2 数据库会话管理
- 使用 SQLAlchemy 异步会话（`AsyncSession`）；
- FastAPI 依赖注入每个请求一个会话，请求结束自动关闭；
- 使用 Alembic 管理表结构变更。

### 5.3 LangGraph 状态持久化
- 使用 `SqliteSaver` 或 `PostgresSaver` 作为 Checkpointer；
- 每次节点执行后自动保存 State；
- 支持断点续跑、人机协同、历史状态回放。

### 5.4 MCP 工具接入
- 通过 `mcp` 包或 `langchain-mcp-adapters` 连接 `amap-mcp-server`；
- MCP Server 通过 `uvx amap-mcp-server` 启动，传入 `AMAP_MAPS_API_KEY`；
- Agent 调用工具时由 LangChain 自动处理参数和结果。

### 5.5 异常处理
- FastAPI 全局异常处理器统一返回 `{success: false, message: ...}`；
- Agent 节点内部异常被捕获，写入 `state["error"]`；
- JSON 解析失败时调用 `json_parser.py` 进行修复，修复失败再兜底。

## 6. 与前端的协作边界

| 后端职责 | 前端职责 |
|----------|----------|
| 用户认证与 JWT 签发 | Token 存储与请求携带 |
| LangGraph 执行与状态持久化 | 通过 SSE 接收并展示状态 |
| 调用 LLM、MCP、向量库 | 不直接调用，全部通过 API |
| 数据库读写 | 不接触数据库 |
| 地图数据计算 | 地图可视化渲染 |
| 订单创建与回调 | 支付页面展示与跳转 |
| 日志与监控 | 前端错误上报（可选） |

后端是整个系统的「大脑」，负责 AI 推理、数据持久化、外部服务集成；前端是「表现层」，负责把后端的推理过程和结果可视化地呈现给用户。
