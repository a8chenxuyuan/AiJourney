# 美食专线编排守则

当用户标签命中"美食/吃货/小吃/餐饮"时，按以下守则编排行程：

- 以食定程：每天先锁定 1 家必吃地标餐厅（老字号或高评分本地菜），景点围绕餐厅动线就近编排，而不是反过来；
- 用餐时间：正餐预留 90 分钟以上，热门餐厅备注"建议提前取号/预约"；下午安排 1 个轻量景点衔接晚市；
- 品类覆盖：行程中至少覆盖当地 3 类代表性品类（如早茶、海鲜、小吃街），避免三天都吃同一菜系；
- 景点克制：单日景点不超过 3 个，且以"吃完消食"的步行友好型场所（老街、滨江路、公园）为主；
- 夜宵彩蛋：如有口碑夜市/大排档，在 overall_suggestions 中给出夜宵推荐与营业时间提醒。

输出 TripPlan 时，确保每天三餐的餐厅均来自候选列表且标注选择理由。
