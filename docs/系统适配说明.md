# agent1旅行 · 系统适配说明

> 本文档说明系统在不同平台、硬件、依赖环境下的适配情况与已知限制，
> 供部署评估、环境选型与故障排查参考。与《部署文档.md》配合阅读。

---

## 一、平台适配

### 1.1 操作系统

| 平台 | 适配状态 | 说明 |
|------|----------|------|
| Windows 10 / 11 x64 | ✅ 已验证（当前开发环境） | 后端以 `venv\Scripts\python.exe run.py` 启动；路径均为 UTF-8 安全写法 |
| Linux x86_64（Ubuntu 20.04+/Debian/CentOS） | ✅ 兼容 | 生产推荐；Redis/Qdrant 以 systemd 或 Docker 管理 |
| macOS（Apple Silicon / Intel） | ✅ 兼容 | 前后端均可运行；sentence-transformers 首次编译依赖可能较慢 |
| Windows Server | ✅ 兼容 | 建议用 NSSM/任务计划注册后端与 Worker 为系统服务 |

> 项目内所有文件路径均使用 `pathlib` 相对定位（如 `.env`、日志目录），
> 不依赖盘符或绝对路径，跨平台迁移无需改代码。

### 1.2 浏览器（前端）

| 浏览器 | 最低版本 | 依据 |
|--------|----------|------|
| Chrome / Edge | 90+ | Vue3 + Vite 构建目标（ES2015+）、EventSource（SSE） |
| Firefox | 88+ | 同上 |
| Safari | 14+ | SSE 支持；需注意代理层不缓冲 `text/event-stream` |

核心依赖特性：`EventSource`（SSE 实时进度）、`fetch`（含 `AbortController`）。
不支持 IE 全系列。

### 1.3 服务端运行形态

- 后端 API 与 Agent Worker 为**两个独立进程**，通过 Redis 队列解耦，可分别重启、分别部署。
- 开发模式 `reload=False`（热重载会中断后台任务），改动后端代码后需手动重启。

## 二、硬件适配

### 2.1 资源需求

| 场景 | CPU | 内存 | 磁盘 | 说明 |
|------|-----|------|------|------|
| 纯 API（无 Embedding） | 2 核 | 2 GB | 2 GB | 关闭 RAG/爬虫的最小形态 |
| 完整功能（含 Embedding） | 4 核 | 8 GB | 10 GB | Embedding 模型 bge-large-zh 约 1.3 GB，加载峰值约 2 GB |
| 多用户并发 | 8 核 | 16 GB | 20 GB | LLM 调用为 IO 密集，CPU 压力主要在 JSON 解析与向量化 |

### 2.2 资源敏感点

- **内存**：`sentence-transformers` 加载 Embedding 模型是最大内存项；低配机器可在
  `.env` 将 `EMBEDDING_MODEL_NAME` 换为 `paraphrase-multilingual-MiniLM-L12-v2`（约 470 MB）。
- **磁盘**：模型缓存位于用户目录 `~/.cache/huggingface`（Linux/WSL）或
  `C:\Users\<user>\.cache\huggingface`（Windows）。
- **网络**：规划一次行程约调用 LLM 8~12 次（各 Agent 节点），对 API 网络质量敏感；
  Planner 节点单次 LLM 超时上限 300 秒。

## 三、依赖兼容性

### 3.1 运行时

| 依赖 | 兼容范围 | 已验证版本 |
|------|----------|------------|
| Python | 3.10 ~ 3.12 | 3.12.8（不支持 3.13+，langgraph 0.2.x 兼容性未验证） |
| Node.js | 18 LTS+ | 与 Vite 5 / Vue 3 匹配 |
| Redis | 6.0+ | 7.x（ARQ 依赖 asyncio Redis 协议，RESP2/RESP3 均可） |
| SQLite | 3.35+ | 随 Python 内置；`CREATE INDEX IF NOT EXISTS` 需 3.3+ |
| PostgreSQL（可选） | 13+ | 切换 `DATABASE_URL=postgresql+asyncpg://...`，驱动 asyncpg 0.31.0 |
| Qdrant（可选） | 1.12+ | 客户端 qdrant-client 1.18.0；未部署自动降级 |

### 3.2 版本锁定策略

- `backend/requirements.txt` 全部依赖使用 `==` 精确锁定（与验证环境一致），部署可重现。
- langchain 系列版本间依赖约束复杂，**升级时必须成组升级**并回归验证（当前组合见下表）。

| 包 | 锁定版本 |
|----|----------|
| langchain | 0.3.26 |
| langchain-core | 0.3.86 |
| langchain-openai | 0.2.14 |
| langgraph | 0.2.62 |
| langgraph-checkpoint | 2.1.2 |
| langgraph-sdk | 0.1.74 |

### 3.3 外部服务兼容性

| 外部服务 | 用途 | 缺失时行为 |
|----------|------|------------|
| 阿里云百炼（DashScope） | LLM 推理 | 规划/修订不可用（硬依赖），启动不报错、调用时报错 |
| 高德地图开放平台 | POI 检索、路线规划 | 相关 Agent 返回空结果，规划降级为候选列表拼装 |
| 百度百科/必应 | 背景知识实时检索 | 背景知识为空，不影响主流程 |

## 四、已知限制

1. **SQLite 并发写限制**
   SQLite 为单写者模型，高并发写入会触发 `database is locked`。
   仅建议开发/演示环境使用；并发场景切换 PostgreSQL（改 `DATABASE_URL` 即可，ORM 层已兼容）。

2. **revision 并发锁为进程内语义**
   同一 `plan_id` 的修订互斥锁（`asyncio.Lock`）存在于后端 API 进程内存中。
   单实例部署无问题；**多实例部署时**需替换为 Redis 分布式锁，否则跨实例可能并发修订同一行程。

3. **SSE 对反向代理的要求**
   进度推送使用 SSE 长连接。Nginx 需对该路由关闭 `proxy_buffering` 并调大读超时，
   否则会出现进度"卡住"或连接被提前断开。浏览器端 EventSource 断线后会自动重连并回放历史日志。

4. **LLM 网络依赖**
   百炼 API 为境外可达性良好的国内服务，但整体规划链路强依赖外网；
   离线环境下行程规划不可用（本地 LLM 未适配）。

5. **Embedding 离线降级**
   首次运行需联网下载 `BAAI/bge-large-zh-v1.5`；离线且无缓存时 RAG 自动降级为
   "直通模式"（背景知识改由百度百科实时获取），主流程不受影响。

6. **语料与地域范围**
   RAG 语料与 POI 数据以中文城市为主；海外城市仅支持基础规划（无背景知识增强）。

7. **支付为沙箱演示**
   支付模块为支付宝沙箱假流程，不产生真实交易，不可用于生产收费场景。

8. **爬虫默认关闭**
   定时爬虫（APScheduler）默认 `CRAWLER_ENABLED=false`；启用前请确认目标网站
   的 robots 协议与法律法规合规性。

9. **密码学依赖平台差异**
   `passlib+bcrypt` 在部分 Linux 发行版需系统安装 `libffi`；
   `python-jose` 的 cryptography 后端随平台轮子分发，遇到缺失时执行
   `pip install --force-reinstall cryptography==49.0.0`。
